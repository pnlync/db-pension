# Member data (synthetic)

All member data and member experience in this folder are synthetic, generated by `uv run python -m pension.data_gen` (config: `config/data_gen.yaml`, fixed seed). No real person or scheme.

| File | What |
|---|---|
| `members_2024.csv` | opening snapshot at 2024-12-31 (treated as last year's clean, reconciled data) |
| `movements_2025.csv` | simulated 2025 events: salary and pension increases, withdrawals, retirements, deaths |
| `members_2025_raw.csv` | closing administrator extract at 2025-12-31, with about 2% injected errors (answer key: `tests/fixtures/injected_errors.csv`) |
