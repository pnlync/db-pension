# DB Pension Scheme Model

A model of a synthetic Irish final-salary (defined benefit) pension scheme: IAS 19 and the Irish Funding Standard (with the funding standard reserve) on the same member benefits, the 2025 roll-forward, risk, a funding proposal and a pensioner buy-in price.

> All member data and member experience are synthetic. Market data are public and dated. Illustrative implementation based on published Pensions Authority and Society of Actuaries in Ireland guidance; not an actuarial certification or regulatory filing.

Work in progress — build specification: [`SPEC.md`](SPEC.md).
